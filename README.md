# Учебная практика — технологическая (проектно-технологическая) практика

Репозиторий содержит готовые материалы по кейс-заданиям практики.

## Структура

- `case1_array` — решение кейс-задачи №1: сумма отрицательных элементов между максимальным и минимальным.
- `case2_oop` — решение кейс-задачи №2: демонстрация методов базового и производного классов.
- `case3_database` — проект базы данных «Туризм» (MySQL), 5 таблиц, справочники, внешние ключи и тестовые данные.
- `case4_web` — пример WEB-приложения на Delphi 10.2 WebBroker с подключением к MS SQL Server.
- `case5_analysis` — аналитический обзор выполненной работы по критериям качества ПО.

## Быстрый запуск

### Кейс 1
Требуется Python 3.10+:
```bash
python main.py
```

### Кейс 2
Требуется Python 3.10+:
```bash
python main.py
```

### Кейс 3
Откройте `schema.sql` в MySQL Workbench и выполните скрипт целиком.

### Кейс 4
Проект рассчитан на Delphi 10.2 Tokyo и IIS. Перед запуском:
1. Создайте базу MS SQL Server по `database.sql`.
2. Откройте `TourismWeb.dproj` в Delphi 10.2.
3. Укажите параметры подключения в `WebModuleUnit.pas`.
4. Соберите ISAPI DLL.
5. Настройте IIS на запуск DLL как ISAPI-приложения.
