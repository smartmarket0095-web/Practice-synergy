# Кейс-задача №5 — аналитический обзор

## 1. Функциональность
Все основные функции реализованных кейсов соответствуют поставленным задачам:
обработка массива, демонстрация ООП, хранение данных в реляционной БД и выдача
данных WEB-приложением.

**Оценка: 5/5.**

## 2. Производительность
Алгоритм кейса №1 выполняется за O(N). Операции с БД используют индексы по
часто используемым полям. WEB-приложение получает только необходимые поля.

**Оценка: 4/5.**

## 3. Удобство использования
Программы имеют понятный консольный вывод. WEB-интерфейс содержит минимальную
навигацию и API для получения списка туров.

**Оценка: 4/5.**

## 4. Безопасность
Для промышленного внедрения необходимо хранить пароль БД вне исходного кода,
использовать отдельную учётную запись БД с минимальными правами, HTTPS и
защищённую конфигурацию IIS.

**Оценка текущего учебного прототипа: 3/5.**

## 5. Масштабируемость
Структура БД разделена на справочники и транзакционные таблицы. Проект допускает
добавление новых типов туров, услуг и клиентов без изменения основной архитектуры.

**Оценка: 4/5.**

## 6. Сопровождаемость
Код разделён по кейсам, снабжён README и комментариями. SQL-схема хранится
отдельным файлом.

**Оценка: 4/5.**

## 7. Переносимость
Кейсы №1 и №2 запускаются на Python. SQL-части зависят от соответствующей СУБД.
WEB-кейс требует Delphi 10.2, IIS и MS SQL Server.

**Оценка: 3/5.**

## 8. Качество кода
Использованы классы, функции, ограничения БД, внешние ключи, индексы и
структурированная организация репозитория.

**Оценка: 4/5.**

## 9. Тестирование
Проверены базовые сценарии: корректный массив, ООП-полиморфизм, создание БД,
заполнение тестовыми данными и получение списка туров.

**Оценка: 4/5.**

## Итог
Средняя оценка прототипа: **4,0/5**.

### Предложения по улучшению
1. Добавить автоматические модульные тесты.
2. Вынести параметры подключения к БД в конфигурационный файл.
3. Добавить авторизацию пользователей.
4. Использовать HTTPS в IIS.
5. Добавить полноценные CRUD-операции для туров и заказов.
6. Добавить журналирование ошибок и событий.
